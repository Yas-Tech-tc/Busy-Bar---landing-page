# BUSY Bar - Landing Page

Landing page réalisée pour le produit **BUSY Bar**, un dispositif de productivité avec écran LED permettant d'afficher son statut "occupé" pour éviter les interruptions pendant les phases de concentration.

Ce projet a été développé dans le cadre d'une **formation Tailwind CSS**, dans le but de mettre en pratique les concepts de mise en page responsive, d'utilitaires CSS et de design moderne avec Tailwind.

## Technologies utilisées

- HTML5
- Tailwind CSS

## Fonctionnalités de la page

- Section héro avec vidéo de fond
- Présentation des fonctionnalités du produit
- Section dédiée à l'activation du statut "Busy"
- Design responsive

## Aperçu

Landing page statique, aucune installation nécessaire — il suffit d'ouvrir `index.html` dans un navigateur.
